# Исследование быстродействия пневматического золотникового распределителя

Web-панель лабораторного стенда для моделирования, визуализации и анализа быстродействия пневматического золотникового распределителя 5/2.

## Возможности

- инженерная модель переключения прямого и обратного хода;
- расчёт времени срабатывания по достижению 90% / 10% хода;
- визуализация активных каналов распределителя и потоков воздуха;
- график команды, положения золотника и расхода;
- отчёты по завершённым запускам;
- страница методики измерения;
- черновые материалы для патентной подготовки и регистрации программы для ЭВМ.

## Запуск

```bash
npm install
npm run dev
```

## Проверка

```bash
npm run build
npm run lint
```

## Разделы

- **Стенд** — запуск эксперимента: схема, кривая хода, время срабатывания tср.
- **Расчёт** — калькулятор динамики переключения по фазам.
- **Каталог** — сравнение распределителей по данным из даташитов.
- **Конфигуратор** — схема подключений стенда и бюджет погрешности.
- **Утилиты** — пересчёт Cv/Kv/Qn/C и потери давления в линии.
- **Методика** и **Отчёты**.
